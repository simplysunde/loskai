Certificate

Install this once per device and every internal site is trusted — including ones added later.

1Download the certificate

Your browser will warn you that you're installing something. That's expected — this file is a certificate, not a program, and it can't run.

caddy-root.crt

2Add it to your trust store

  1. Double-click caddy-root.crt in your Downloads folder.
  2. Click Install Certificate, choose Local Machine, then Next.
  3. Choose Place all certificates in the following store — the default “Automatically select” puts it in the wrong one and the warning stays.
  4. Browse to Trusted Root Certification Authorities, then Next and Finish.
Or, in PowerShell as Administrator
certutil -addstore -f "ROOT" "$env:USERPROFILE\Downloads\caddy-root.crt"
Run in Terminal — you'll be asked for your password
sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain ~/Downloads/caddy-root.crt

That covers Safari and Chrome. On an iPhone or iPad, open the file in Safari, then install it under Settings → General → VPN & Device Management, and switch it on under Settings → General → About → Certificate Trust Settings.

Debian, Ubuntu, Mint, Raspberry Pi OS
sudo cp ~/Downloads/caddy-root.crt /usr/local/share/ca-certificates/
sudo update-ca-certificates
Fedora, RHEL, Rocky, Alma, CentOS
sudo cp ~/Downloads/caddy-root.crt /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust
Arch, openSUSE (p11-kit)
sudo trust anchor --store ~/Downloads/caddy-root.crt

The Debian tool only picks up files ending in .crt — keep the name as it downloaded.

Chrome and Chromium keep a separate store on Linux — add it there too
certutil -d sql:$HOME/.pki/nssdb -A -t "C,," \
  -n "Caddy Local Authority" -i ~/Downloads/caddy-root.crt

certutil comes from nss-tools (Fedora) or libnss3-tools (Debian).

  1. Download caddy-root.crt above. Opening it doesn't install it.
  2. Open Settings › Security & privacy › More security & privacy › Encryption & credentials › Install a certificate › CA certificate. On a Samsung: Security and privacy › More security settings › Install from device storage › CA certificate.
  3. Tap Install anyway, then pick caddy-root.crt from Downloads. Without a screen lock, Android asks you to set one first.

A notice then says the network may be monitored: that is any certificate you install yourself. Chrome and Samsung Internet trust it now. Firefox does once you turn on Use third party CA certificates under Settings › Secret Settings (tap the logo in About Firefox five times to show them). Many apps never trust it: for those, serve the name over HTTP too.

Firefox keeps its own trust store and ignores the system one on every platform. Open Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import, pick the file, and tick “Trust this CA to identify websites”.

3Check it worked

Open any internal site over https:// and look for the padlock. Already had a tab open? Reload it — browsers cache the old failure. You won't have to do this again on this device.
